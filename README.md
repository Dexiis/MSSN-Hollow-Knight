# Projeto MSSN (Modelação e Simulação de Sistemas Naturais)

## Contexto
Este projeto foi desenvolvido para a unidade curricular de **Modelação e Simulação de Sistemas Naturais (MSSN)** do curso LEIM (DEI - ISEL). Consiste numa demo de jogo que recria uma pequena área de mapa e um combate contra um Boss, focado na aplicação prática de conceitos de simulação.
